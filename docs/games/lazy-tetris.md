## About

It's like Tetris, but all stressful elements have been removed to make it more relaxing.

No timer, no gravity, move a piece around with no pressure, and set it when you are ready.

You can even undo, as many times as you like.

My favorite part of Tetris is stacking blocks, so this game is only that.

Also, the lines do not clear unless you decide to clear them, which allows you to make really tall stacks.

By now, the game is super over-engineered.  The playing grid is infinite, and it supports online co-op.
